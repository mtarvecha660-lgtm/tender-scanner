Make a new data key

This page makes a random key inside your phone/PC. It is not sent anywhere. Use it only when you want to lock out every device (including ones that ticked "Remember me").

  1. Save this key somewhere private (e.g. your password manager). GitHub will not show it again.
  2. GitHub repo → Settings → Secrets and variables → Actions → TS_DATA_KEY → ✏️ → paste → Update secret.
  3. Actions → scan → Run workflow. After ~5 min everyone logs in again with their password.
  4. On the GeM PC: double-click setup.bat, press Enter for the token, paste this new key.
